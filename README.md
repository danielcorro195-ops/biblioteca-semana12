# 📚 Biblioteca Escolar - Semana 12

## Descripción

Sistema web desarrollado para la Biblioteca Escolar "Saber Digital" utilizando HTML5, CSS3, JavaScript (ES6+) y Bootstrap 5. El proyecto aplica los principios de Programación Orientada a Objetos (POO) para gestionar un catálogo de libros mediante una interfaz moderna, accesible y responsiva.

## Características

- 📖 Visualización del catálogo de libros.
- ➕ Registro de nuevos libros.
- 🚫 Validación para evitar libros duplicados.
- 🏷️ Clasificación por categorías.
- 📊 Reporte de libros más leídos.
- 🌙 Tema oscuro y claro.
- ♿ Accesibilidad mediante atributos ARIA.
- 📱 Diseño responsivo con Bootstrap 5.

## Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript ES6+
- Bootstrap 5
- Programación Orientada a Objetos (POO)

## Estructura del Proyecto

```
biblioteca-semana12/
```

## Objetivo

Desarrollar una aplicación frontend que permita administrar el catálogo de una biblioteca escolar de forma organizada, aplicando conceptos de Programación Orientada a Objetos e interfaces modernas con Bootstrap.
